# OrangeGel Official Site (`orangegel/site`)

Official marketing and live interactive demo site for **[OrangeGel](https://github.com/orangegel/orangegel)** — the modern Tauri v2 Static Site IDE & Multi-Device Preview Studio (**Hugo Preferred** + Top 20 Static Site Generators).

## Highlights
- **Built with Hugo** (`hugo.toml`), styled with Citrus-Gel dark glassmorphism (`#0C0D12`, `#FF8A00`, `#FFB800`), Tailwind CSS, Three.js reactive WebGL hydrogel orb, and Anime.js micro-interactions.
- **Pre-configured for OrangeGel Studio** via `.orangegel/project.json` and `.orangegel/dictionary.txt`.
- **Firebase Hosting Ready** via `firebase.json` targeting GCP project `jasonsmithio`.

## Local Development
Open this directory in `OrangeGel.app` and click **Start Server**, or run via the Hugo CLI:

```bash
hugo server -D
```
