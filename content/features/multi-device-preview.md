## Real-Time Multi-Device Preview Browser

OrangeGel embeds a full-featured **Multi-Device Preview Browser** directly beside the Monaco editor so you never have to context-switch between terminal windows and external browser tabs.

### Supported Viewport Modes

1. **Desktop Mode** — Fluid responsive canvas, Laptop 13" (`1280×800`), Desktop HD (`1440×900`), and Desktop 1080p (`1920×1080`).
2. **Tablet Mode** — iPad Mini (`768×1024`), iPad Air (`820×1180`), and iPad Pro 12.9" (`1024×1366`) with one-click Portrait/Landscape rotation.
3. **Mobile Mode** — iPhone SE (`375×667`), iPhone 16 Pro (`393×852`), and Pixel 9 (`412×915`) with interactive device bezels.
4. **Split Matrix Mode** — Simultaneous 3-up stage rendering **Desktop (`1280×800`)**, **Tablet (`768×1024`)**, and **Mobile (`393×852`)** side by side.
